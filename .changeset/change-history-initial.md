Initial release of the change history plugin: entities, options with validation, the `ChangeHistoryService` facade (`recordAction`, `recordRun`, `runBatch`), the before-state and archive storage strategies, the `changeHistoryEntries` Admin API query behind the new `ReadChangeHistory` permission, and a dashboard feed with a `./dashboard` entry for host registrations.
